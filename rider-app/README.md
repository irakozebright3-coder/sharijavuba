# Urubuga rw’umumotari — SharijaVuba

Iyi ni imigaragarire ifasha umukoresha kwandika nimero ya plaque, guhitamo sitasiyo n’ubwoko bwa bateri, gufata umwanya mu murongo no kureba aho ageze.

Urubuga rukoresha HTML, CSS na JavaScript isanzwe, nta framework cyangwa build step bisabwa. Reba README iri mu mizi y’umushinga kugira ngo ubone amabwiriza yo kuyikoresha no kuyishyira kuri internet.
