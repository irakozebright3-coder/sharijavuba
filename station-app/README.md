# Urubuga rwa sitasiyo — SharijaVuba

Uru ni urubuga rukoreshwa n’umukozi wa sitasiyo mu gucunga umurongo w’abakiriya. Rukoresha dosiye imwe ya `index.html`, HTML, CSS na JavaScript isanzwe. Nta framework cyangwa build step bisabwa.

## Uko warukoresha

1. Tangiza backend ukoresheje `cd backend && npm start`. Igomba kuba kuri `http://localhost:3000`. Niba iri ku yindi aderesi, hindura constant ya `API` iri hejuru mu gice cya `<script>` muri `index.html`.
2. Fungura `index.html` muri browser. Kuyifungura muri mudasobwa ubwayo birashoboka.

Database igomba kuba irimo nibura sitasiyo imwe kugira ngo igaragare mu rutonde rwo guhitamo. Ubwoko bwa bateri busomwa mu myanya isanzwe iri muri database; database irimo ubusa ishobora kugaragaza ubwoko bwa `standard` gusa.

## Ibyo urubuga rukora

- Kugaragaza abakiriya bari mu murongo n’abageze hafi.
- Guhamagara umukiriya ukurikiraho.
- Kugaragaza uko buri mwanya uhagaze no gufasha umukozi kwemeza ko umukiriya yageze cyangwa yahawe serivisi.
- Kugaragaza umubare wa bateri zihari, igihe iyo mikorere ibonetse.

Ku mabwiriza yo gushyira backend na frontend kuri internet, reba README iri mu mizi y’umushinga.
